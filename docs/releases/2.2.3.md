# AriaNg 2.2.3

## 修复

- 修复 Gulp 的 lint 任务没有实际执行 ESLint、且可能把源文件写回的问题；构建和 CI 现在会在源码检查失败时可靠终止。
- 修复状态页销毁后仍保留根作用域监听器的问题。
- 修复 WebSocket 已连接但 RPC 不返回时请求一直挂起、连接状态未更新的问题；超时请求不会在重连后重放。

## 优化

- 精简 BT 小文件过滤的批量调度状态、不可达分支和重复扫描，同时保留停止、重启、迟到回调、暂停归属及恢复语义。
- 活动 BT 任务更改文件选择后由 aria2 处理重启，前端不再主动暂停和恢复；保留旧版暂停检查点的恢复支持。
- 简化新建任务页的固定标签切换与 All-In-One 语言资源缓存，减少重复数组构造和不必要的通用路径处理。
- 删除未使用的 `gulp-sourcemaps` 直接依赖及其锁文件条目。

## 维护

- 为真实 lint 执行、语言缓存、迟到回调、标签切换和大文件列表扫描增加回归测试。
- 补充标准版与 All-In-One 产物的离线语言、移动端明暗主题和归档结构验证记录。
