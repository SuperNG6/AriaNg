# AriaNg 2.2.6

## 修复

- 修复设置“新建任务后打开任务详情”时，若批量提交中第一个链接失败，会打开无效详情页的问题；现在会打开第一个创建成功的任务。
- 修复连接多个 aria2 时，新连接的新建任务页会预填另一台服务器刚用过的下载路径的问题。路径历史只记录在各自的连接下，升级前的旧历史仍可作为回退。
- 修复通过 URL 命令（`#!/new/<base64url>?dir=`）新建任务时，空的下载路径被提交给 aria2、文件落到 aria2 工作目录的问题。所有新建入口都不再提交空的必填选项。
- 修复 aria2 返回空响应时，部分操作（如拖动排序）一直等不到结果、任务列表停止刷新的问题。
- 修复页面中的程序错误被误报为“无法连接 aria2”的问题。
- 修复拖动等待任务后立即切换页面时，上一页的列表数据可能出现在新页面的问题。
- 修复在批量过滤栏清空阈值后，新建任务页的阈值也被清空的问题。

## 改进

- 减少任务列表刷新时读取浏览器存储的次数，任务较多并开启文件列表时更流畅。

## 维护

- 增加对应的回归测试；浏览器验收新增“输入字节值不被改写”的检查。
- 更新下载路径和 BT 过滤维护文档，以及维护规范中关于浏览器验证的说明。
