# AriaNg 2.2.7

本版本没有功能变化，主要是验收和文档维护。

## 改进

- BT 小文件过滤的英文提示改为单复数通用的写法，例如不再显示“1 tasks”。

## 维护

- 新增真实 aria2 验收脚本 `test/aria2/run.sh`，只需要 Docker。它用一次性的 aria2c 容器（两个下载端、一个做种端和本地 tracker）驱动构建后的 AriaNg，回读任务目录、队列顺序、文件选择和磁盘上的实际文件。
  - 覆盖新建任务的下载路径、URL 命令、多 RPC 路径历史、详情页跳转和 WebSocket 拖动排序。
  - 覆盖 BT 小文件过滤的端到端流程：本地种子、磁力和远程种子的立即／稍后下载、全部小文件、批量过滤、关页后恢复、重复 InfoHash 复用，以及做种期间和结束后的磁盘状态。
- 删除新建任务页中多余的下载路径去空白代码；Angular 文本输入框本来就会去掉首尾空白，行为不变。
- 修正文档：
  - 2.2.6 发版说明中的 URL 命令格式，并删去不准确的“自动去掉首尾空格”说明；
  - BT 过滤文档中的删除时机：被排除的文件在任务做种结束（或做种中被删除）时才清理，做种期间可能仍在磁盘上。
- 维护规范补充项目重点和真实 aria2 验收说明。
