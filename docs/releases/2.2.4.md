# AriaNg 2.2.4

## 上游同步

- 合并上游 AriaNg 1.3.15，批量操作改为使用 `system.multicall`，减少 RPC 请求数量。
- 容量显示改用 KiB、MiB、GiB 等二进制单位。
- 路径历史下拉框优先读取当前 RPC 的记录，保留本分支既有的连接身份快照和旧历史兼容。
- 同步上游 GitHub Actions 构建流程，移除旧 CircleCI 配置及每日构建脚本；上游发布任务仅在上游仓库运行，避免与本分支发布流程重复。

## 修复

- 合入远端 BT 恢复修复：观察到任务已运行后释放旧暂停归属，避免恢复时接管用户后续暂停；系统时间回拨后重新计算批量重试等待时间。
- 适配批量 RPC 的逐项结果，保留成功标记、任务上下文和输入顺序，确保成功创建的磁力与远程种子任务继续进入 BT 小文件过滤队列。
- 修复批量操作全部失败时被误判为成功的问题，保留部分失败和传输错误的处理。

## 维护

- 增加新建任务控制器、任务服务、RPC 服务和过滤持久化队列的跨模块回归测试，覆盖立即／稍后下载、部分失败、全部失败及延迟回调时的意图快照。
- 增加 `npm run test:browser`，依次构建和检查标准版与 All-In-One 版，覆盖 375px 明暗主题、路径历史隔离、过滤徽章及单文件版离线语言切换。
- 补充上游合并基线、标签命名、冲突处理约定及验收工具说明。
