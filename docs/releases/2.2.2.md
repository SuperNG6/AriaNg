# AriaNg 2.2.2

## 修复

- 修复 WebSocket 重连后可能发送已经失败、且不再有回调接管的排队写请求。
- 修复修改 RPC 设置但尚未刷新时，过滤队列身份与实际连接地址不一致的问题。
- 自动 BT 小文件过滤与恢复现在会等待文件选择和清理选项稳定收敛；必要时执行可恢复的暂停与继续，并保留用户自己的暂停状态。
- 修复种子目录名为 `constructor`、`__proto__` 或 `toString` 时文件树崩溃的问题。
- 修复任务已被删除时重试 Promise 不结束，以及批量重试重复执行失败项、提前报告完成的问题。

## 维护

- 增加真实 WebSocket 依赖、RPC 配置、目录树、单项重试和批量重试回归测试。

BT 未选文件仍由 aria2 在下载完成时按其配置处理。
